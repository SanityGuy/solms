# SoLMS
SoLMS is a custom LMS (Learning Management System) produced and programmed alone by [SanityGuy](https://github.com/SanityGuy) with Laravel Blade & Fortlify for a reusable & reliable program made for schools & libraries.

## Stack & Libraries
This project uses the following:
- Laravel
- Blade
- Fortlify
- TailwindCSS
- Vite
- SQLite
- PHP
